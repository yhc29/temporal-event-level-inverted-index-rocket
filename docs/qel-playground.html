Interval-ensemble semantics

Each label is a finite union of closed intervals. Displacement, ◊, and □ are implemented as endpoint translation, future-window dilation, and future-window erosion; conjunction is intersection.

Finite witnesses, not sampling

For each seizure episode the demo enumerates boundary-derived candidates for x, a, b, and c, then verifies every candidate with the interval semantics. The preferred witness aligns the tonic window with the first clonic onset.

Deliberate edge cases

P03 has no P, P04 has a 3 s postictal gap, P05 reverses T and C, P06 has brief suppression, P08 has pre-ictal P, and P09 has T outside S. Change the preset or filter to see which records survive.
